Fake News Detection Project

This project uses Machine Learning to detect whether news is REAL or FAKE using Streamlit.

Technologies Used:
- Python
- Scikit-learn
- Pandas
- Streamlit

How it works:
1. User enters news text
2. Text is processed using TF-IDF Vectorizer
3. Machine Learning model predicts REAL or FAKE news
4. Result is displayed in Streamlit app
